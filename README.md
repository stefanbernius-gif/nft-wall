# NFT Wall

A museum wall for NFTs on Ethereum, Arbitrum and Optimism. One static HTML file, no login, no server.

- Paste public wallet addresses (or ENS names). NFTs load from the free Blockscout explorer APIs.
- Arrange: drag frames, star favorites (larger gilded frame), hide pieces, pick a wall color, rename the wall.
- "Copy share link" puts the addresses and the arrangement into the URL. Nothing is stored on a server.
